# To-Do List

A simple browser-based to-do list app built with HTML, CSS, and vanilla JavaScript. It lets users add tasks to a list and remove them when they are no longer needed.

## 🚀 Project intro

This project is a lightweight web application for managing everyday tasks. The interface includes an input field, an add button, and a dynamic task list that updates as the user interacts with it.

## 🔧 Features

- Add a task using the input field and the Add to list button
- Display each task as a list item on the page
- Remove a task by clicking its delete button
- Apply basic styling and hover effects for a cleaner interface

## 🧰 Tech stack

- HTML
- CSS
- JavaScript

## ⚙️ Getting started

1. Clone or download this repository.
2. Open the project folder in your browser.
3. Open the index.html file to start using the app.

## 📝 Usage

- Enter a task in the input field.
- Click Add to list to add it to the page.
- Click delete next to a task to remove it.
